Política de Privacidade: RiftStream Bag Cleaner

Última atualização: 13 de novembro de 2026

Português

O que é a extensão. O RiftStream Bag Cleaner é uma extensão de navegador com um único propósito: organizar a mochila do jogo RiftStream, aplicando as regras definidas pelo próprio usuário por raridade de item (favoritar, forjar, vender ou ignorar).

Onde ela funciona. Somente nas páginas de riftstream.com.br. Ela não funciona em nenhum outro site e não acessa outras abas, histórico de navegação ou cookies.

O que ela lê. Na página do jogo, a extensão lê os itens da mochila e da forja (nome, raridade, nível, gemas e se está favoritado) apenas para decidir o que fazer com cada um e clicar nos botões do próprio jogo. Essas informações são processadas no seu navegador, no momento do uso, e não são guardadas.

O que ela guarda. Apenas as suas preferências, no armazenamento local do navegador (chrome.storage.local): a ação escolhida para cada raridade, as opções de pergaminho, o modo simulação, o modo automático e o estado do painel. Essas informações ficam no seu aparelho.

O que ela não faz.

  • Não coleta dados pessoais, de saúde, financeiros, de autenticação ou de comunicação.
  • Não envia nenhum dado para servidores, para o desenvolvedor ou para terceiros.
  • Não usa análises, rastreadores, anúncios nem código remoto.
  • Não vende nem transfere dados de usuários.
  • Não usa dados para fins alheios ao seu propósito único.

Como apagar os dados. Remover a extensão do navegador apaga as preferências guardadas.

Mudanças. Se esta política mudar, a nova versão será publicada nesta mesma página, com a data atualizada.

Contato. Abra uma issue no repositório do projeto no GitHub (aba Issues).

English

What the extension is. RiftStream Bag Cleaner is a browser extension with a single purpose: organizing the inventory of the RiftStream game by applying rules defined by the user per item rarity (favorite, forge, sell or ignore).

Where it runs. Only on riftstream.com.br pages. It does not run on any other site and does not access other tabs, browsing history or cookies.

What it reads. On the game page, the extension reads the inventory and forge items (name, rarity, level, gems and favorite status) only to decide what to do with each one and to click the game's own buttons. This information is processed in your browser at the time of use and is not stored.

What it stores. Only your preferences, in the browser's local storage (chrome.storage.local): the action chosen for each rarity, scroll options, simulation mode, automatic mode and panel state. This information stays on your device.

What it does not do.

  • It does not collect personal, health, financial, authentication or communication data.
  • It does not send any data to servers, to the developer or to third parties.
  • It uses no analytics, trackers, ads or remote code.
  • It does not sell or transfer user data.
  • It does not use data for purposes unrelated to its single purpose.

How to delete data. Removing the extension from the browser deletes the stored preferences.

Changes. If this policy changes, the new version will be published on this same page with an updated date.

Contact. Open an issue in the project repository on GitHub (Issues tab).
